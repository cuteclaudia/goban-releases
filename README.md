<h1 align="center">碁盤 Goban</h1>
<p align="center"><i>Spreadsheets and data. Part of 工房 Kōbō, by CuteClaudia.</i></p>

Goban is CuteClaudia's spreadsheet app for **Windows and Linux**: open, edit and save Excel
workbooks (.xlsx) and CSV files, with formulas, charts, tables and pivot tables.

## Download

Get the latest version from **[Releases](https://github.com/cuteclaudia/goban-releases/releases/latest)**.

| System | File |
|---|---|
| Windows 10/11 | `goban-<version>-windows-x64-setup.exe` (installer) or `…-portable.zip` |
| Linux, any distro | `goban-<version>-linux-x86_64.AppImage` |
| Debian, Ubuntu, Mint | `goban-<version>-linux-x86_64.deb` |
| Fedora, openSUSE | `goban-<version>-linux-x86_64.rpm` |

Each release lists SHA-256 checksums in `SHA256SUMS.txt`, so you can check your download.

## Privacy

Goban has no account, no telemetry and no analytics: your workbooks stay where you save them. It
asks this page whether a new version is out. Every release passes a security check first: known
vulnerabilities, where the code comes from, every connection the program can make, and a virus
scan. See [PRIVACY.md](PRIVACY.md).

## Problems and ideas

Please [open an issue](https://github.com/cuteclaudia/goban-releases/issues/new). Don't attach real
workbooks or personal data.
